# PC FISH 1.7.0 호환성 검토

2026-11-17, Steam build 26614171 / Automation 0.5.1 호환성 검토다. 아래 실사용 기록은 최초 로컬 설치 당시의 근거이며 장시간 안정성 검증은 포함하지 않는다.

## 변경과 연결부

- 이전 검증 대상은 1.6.2 / build 26315872다. 새 바이너리 SHA-256은 `832C9EB6DB770DE6F489BAA6EAAA84A45BBFBABB31895757DDD4EA92D26A0E7F`다.
- Il2CppDumper로 두 버전의 Assembly-CSharp 625개 및 firstpass 470개 타입을 비교했다. DLC 006 설정·소유 여부 필드, 장식 목록 콜백이 추가됐다. 일부 정적 필드 위치가 바뀌었지만 모드는 필드 이름으로 생성된 interop를 사용한다.
- 교배·합성·제작·재고 복구 콜백과 저장·레벨업 함수 시그니처 및 물고기 모델 구조는 유지됐다. 새 게임이 생성한 interop 참조로 빌드했다.
- 기존 분석 대상 32개 네이티브 함수의 호출 목록을 비교했다. 게임 함수 호출 목록은 유지됐다. 세 함수에서 공유 제네릭 코드의 덤퍼 표시 이름이 바뀌었으며, 컴파일된 명령·레지스터 배치 자체는 달라졌다. 바이너리 전체의 의미 동등성을 증명한 것은 아니다.
- 추출한 TextAsset을 이름으로 대조했을 때 내용 변경이나 추가가 없었다. 물고기·교배 레벨·수조·시즌 레시피 CSV가 여기에 포함된다.

## 수정과 검증

플러그인·설치 스크립트의 검증 대상 해시와 패키지 메타데이터를 새 게임에 맞췄다. 미검증 빌드 거부는 유지한다. 설치 기록의 게임 해시도 업데이트 시 갱신한다. 기존 정책·설정·요청 기록은 유지한다.

- 새 interop 기반 Release 빌드: 경고 0, 오류 0.
- `dotnet run --project tests/ModGuard -c Release`: 실행 보호 816건 통과.
- `python -m unittest discover -s tests`: 217건 통과. 게임 연결 기반이 바뀌므로 계획기 소비자 회귀까지 전체 Python 검사를 수행했다.
- `tests/Test-InstallScripts.ps1`: 미지원 빌드·실행 중 설치 거부, 설치·업데이트·기존 설정 보존·해시 갱신·제거 통과. 격리된 가상 파일을 사용한 검사다.

## 로컬 실행 확인

게임을 정상 종료하고 기존 DLL·설정·세이브를 백업한 뒤 설치했다. Steam 재실행에서 0.5.1 로드, 응답 후크 활성화, 서버 재고 560마리 동기화 및 계획기 자동 시작을 확인했다. 기존 설정 파일의 바이트는 동일하다.

08:00:43 KST 자동 교배의 원래 게임 저장이 완료됐고 08:01:44 서버 재고에서 결과를 확인했다. 해당 이벤트는 `confirmed=true`, `synthetic=false`이며 물고기 560→561, 하트 5→4, 비용 차감 1회로 기록됐다. 이후 미확정 요청 없이 다음 행동 간격 대기로 복귀했다. 합성·시즌 제작·레벨업의 이번 버전 실사용과 장시간 안정성은 미검증이다.

로컬 분석 원본·실행 증거·백업은 `work/compat-20261117/`에 보존한다. 롤백은 게임을 정상 종료한 뒤 백업 DLL과 설정을 복원한다. 이전 DLL은 새 게임에서 자동화를 차단하며, 게임 진행을 되돌리지 않는다.

## 공개 전 추가 검수

원격 0.5.0 이후의 교배 계획 개선도 함께 검수했다. 부모 희귀도가 다른 관측을 별 등급만으로 합치던 문제를 수정하고, 동일 부모 희귀도·별 조합과 결과 희귀도의 표본이 5건 미만이면 명시적인 탐색 기준으로 처리한다. 결과별 표본 중 최솟값을 표시해 마지막 결과의 표본만 보고하던 혼동도 없앴다. 이 수정 후 Python 전체 219건, C# 실행 보호 816건, 격리 설치 검사를 통과했다. 앞의 실사용 교배 기록은 이 추가 계획기 수정 전의 호환성 검증이며, 동일한 DLL을 사용한다.
